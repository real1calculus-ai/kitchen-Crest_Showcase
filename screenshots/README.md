# Screenshot & Visual Demonstration Guide

This folder contains visual capture guidelines for Kitchen Crest.

To protect the business's privacy, every screenshot captured for public display must be taken against seeded demo data only — dummy customer names, fabricated orders, and placeholder figures. Never capture a screen showing a real customer's name, phone number, address, or an actual order.

---

## Recommended Screenshots

### 1. Today Dashboard (`01-today-dashboard.png`)
- **Screen**: `/today`
- **Focus**: At-a-glance open orders, kitchen prep list, and the daily-menu portion toggle.

### 2. Orders List & Detail (`02-orders.png`, `03-order-detail.png`)
- **Screen**: `/orders`, `/orders/[id]`
- **Focus**: Multi-channel order book (channel badges including Chowdeck), status flow controls, and the per-order food-cost/margin breakdown.

### 3. Stand POS Checkout (`04-pos-checkout.png`)
- **Screen**: `/stand`
- **Focus**: Touch-first grid checkout built for a tablet at the food stand.

### 4. Menu & Recipe Builder (`05-recipe-builder.png`)
- **Screen**: `/menu/[id]`
- **Focus**: Ingredient-level recipe lines with live per-portion cost and margin calculation.

### 5. Profit Dashboard (`06-profit.png`)
- **Screen**: `/profit`
- **Focus**: Daily revenue/cost chart and the per-channel breakdown table.

### 6. Chowdeck Sync (`07-chowdeck-settings.png`)
- **Screen**: `/settings` (Chowdeck section)
- **Focus**: The manual sync control and configuration status.

### 7. Native Mobile App (`08-mobile-native.png`)
- **Screen**: The Capacitor-wrapped app on an iOS/Android device or simulator
- **Focus**: Installed-app chrome (status bar, splash, no browser UI), safe-area-aware layout.
